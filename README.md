# Complaint System

A RESTful API backend application built with Python and Flask that allows users to register, log in, and manage complaints efficiently.

## Features

- User Registration and Authentication
- Submit a Complaint
- View All Complaints
- View a Single Complaint
- Update a Complaint
- Delete a Complaint

## Technologies Used

- Python
- Flask
- SQLAlchemy
- Flask-Login
- SQLite
- Git & GitHub

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /auth/register | Register a new user |
| POST | /auth/login | Login a user |
| POST | /complaints | Submit a complaint |
| GET | /complaints | Get all complaints |
| GET | /complaints/<id> | Get a single complaint |
| PUT | /complaints/<id> | Update a complaint |
| DELETE | /complaints/<id> | Delete a complaint |
